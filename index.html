Privacy and data handling

This is a client-side application. JSON files selected or dropped into the dashboard are read by your browser, validated in memory, and used only to render this page. They are not uploaded, stored in local storage, sent to an API, or included in telemetry.

The OpenCode command runs on your machine and writes its JSON output to the path you choose. The public site does not connect to your OpenCode server. Static hosting may receive ordinary web request metadata such as an IP address, browser user agent, and requested asset paths, but it does not receive the contents of your usage export.

External documentation links leave this site and are governed by their own privacy policies. Review any export before sharing it: usage dates, token totals, costs, model names, project paths, and other metadata may be sensitive.
